## 3. จุดตัดขนาดหน้าจอ

ออกแบบ **mobile-first** (เล็ก→ใหญ่)

| ชื่อ | ความกว้าง | อุปกรณ์เป้าหมาย |
|---|---|---|
| mobile | < 640px | มือถือ · **LINE OA in-app browser** (ค่าหลักที่ต้องเทสต์) |
| tablet | 640–1024px | แท็บเล็ต |
| desktop | > 1024px | เว็บเดสก์ท็อป |

การ์ดยอดรวม + allocation เรียงเป็น 1 คอลัมน์บน mobile, 2 คอลัมน์ตั้งแต่ tablet · touch target ≥ 44×44px

## 4. ส่วนประกอบ

ทุกส่วนประกอบต้องมีครบทุกสถานะ · ส่วนประกอบที่มีแต่สถานะปกติคือยังไม่เสร็จ

### 4.1 Button

| รายการ | รายละเอียด |
|---|---|
| ใช้เมื่อไหร่ | สั่งการหลัก (primary=ไลม์), รอง (secondary=ม่วง), ตติยะ (ghost=เส้นขอบ) |
| ไม่ใช้เมื่อไหร่ | เป็นลิงก์นำทาง (ใช้ link) |
| token ที่ใช้ | `--accent`/`--brand`/`--border`, `--radius-control`, `--type-body` |

| สถานะ | ลักษณะ | หมายเหตุ |
|---|---|---|
| ปกติ | primary: พื้นไลม์ #C1FD42 ตัวอักษรดำ #0E0A1C | contrast 16.12:1 |
| เมาส์ชี้ | เข้มขึ้น #AEE62F | |
| โฟกัส | ring 2px #F982FB รอบปุ่ม | **มองเห็นชัดเมื่อใช้คีย์บอร์ด** |
| กด | scale 0.98 + เข้มขึ้น | |
| ปิดใช้งาน | opacity 0.4 + cursor not-allowed | ไม่ใช้สีเทาล้วน |
| กำลังโหลด | spinner + ข้อความ "กำลังบันทึก…" ปุ่ม disable | |
| ผิดพลาด | (ส่งต่อ inline error ใต้ปุ่ม/ฟอร์ม) | ปุ่มไม่เปลี่ยนเป็นสีแดงเอง |

**การเข้าถึง** — `<button>` จริง · โฟกัสด้วยคีย์บอร์ด (Enter/Space) · ป้ายข้อความชัด ไม่ต้องมี aria-label ถ้าข้อความบอกครบ

### 4.2 Delta badge (กำไร/ขาดทุน)

| สถานะ | ลักษณะ | หมายเหตุ |
|---|---|---|
| กำไร | ▲ + จำนวน/% สี `--gain` #3DDC84 | **ต้องมี ▲ และ +** |
| ขาดทุน | ▼ − จำนวน/% สี `--loss` #FF6B6B | **ต้องมี ▼ และ −** |
| เป็นกลาง (0%) | — สี `--muted` | |
| คำนวณไม่ได้ | "—" สี `--muted` | เมื่อไม่มีราคาตลาด (F004 AC-E01) |

**การเข้าถึง** — สื่อด้วยรูปทรง+เครื่องหมาย ไม่พึ่งสี · screen reader อ่าน "กำไร 8.4 เปอร์เซ็นต์"

### 4.3 Price-status badge

| สถานะ | ลักษณะ | หมายเหตุ |
|---|---|---|
| online | จุด `--gain` + "อัปเดตแล้ว HH:MM" | ราคาสดภายใน 15 นาที (BR-01) |
| stale | ป้าย `--warn` #C9A227 + "ราคาเก่า N นาที" | เก่ากว่า 15 นาที/ดึงไม่สำเร็จ |
| offline | ป้าย `--warn` + "ออฟไลน์ ใช้ค่าล่าสุด" | ทั้งพอร์ต (F003 AC-E02) |
| manual | ป้าย `--muted` + "กรอกเอง" | ไม่มีแหล่งรองรับ (F003 AC-03) |

### 4.4 Asset row (ตารางสินทรัพย์)

| สถานะ | ลักษณะ |
|---|---|
| ปกติ | ชื่อ (bold) + broker chip + มูลค่า (tabular) + delta badge + ราคา/price-status |
| เมาส์ชี้ | พื้นแถวสว่างขึ้นเล็กน้อย |
| โฟกัส (แถวคลิกได้) | ring 2px `--highlight` |
| กำลังโหลดราคา | skeleton บนช่องราคา |
| ผิดพลาด | price-status = stale/offline คงค่าเดิม ไม่แสดง 0 |

### 4.5 Allocation donut + legend

| สถานะ | ลักษณะ |
|---|---|
| มีข้อมูล | donut สี categorical (validated CVD-safe) + legend สี+ชื่อ+%+มูลค่า |
| ว่าง | ไม่มีสินทรัพย์ → ไม่แสดง donut แสดง empty state ของหน้า |
| กำลังโหลด | skeleton วงกลม |
| ผิดพลาด | ถ้าราคาบางตัวหาย → donut ใช้ราคาที่มี + flag |

สี categorical (brand-aligned, validated): `#7B72FF` `#F982FB` `#C1FD42` `#9CA3AF`
· ทุกลิ่มมี legend + % กำกับ (ไม่พึ่งสีอย่างเดียว)

### 4.6 Text input (ฟอร์มเพิ่มสินทรัพย์)

| สถานะ | ลักษณะ | หมายเหตุ |
|---|---|---|
| ปกติ | พื้น `--surface-2` เส้นขอบ `--border` | |
| โฟกัส | เส้นขอบ `--brand` + ring 2px | |
| ปิดใช้งาน | opacity 0.4 | |

## 5. ข้อกำหนดหน้าจอ

แต่ละหน้าต้องมีครบ 5 สถานะ: มีข้อมูล · ยังไม่มีข้อมูล · กำลังโหลด · ผิดพลาด · ไม่มีสิทธิ์

### 5.1 หน้าพอร์ตรวม (Portfolio overview)

| รายการ | รายละเอียด |
|---|---|
| ข้อกำหนดที่รองรับ | F002, F004 (+ F003 price status) |
| ผังการไหล | NAV (STAGED — งาน stage นี้/ถัดไป) |

| สถานะของหน้า | เกิดเมื่อไหร่ | ผู้ใช้เห็นอะไร |
|---|---|---|
| มีข้อมูล | มีสินทรัพย์ ≥1 | การ์ดยอดรวม (พื้นม่วง) + delta วันนี้ + donut allocation + ตารางสินทรัพย์ |
| ยังไม่มีข้อมูล | ยังไม่เพิ่มสินทรัพย์ | empty state + ปุ่มไลม์ "เพิ่มสินทรัพย์" (ไม่ใช่หน้าว่าง/error) — F002 AC-E01 |
| กำลังโหลด | ระหว่างดึงราคา | skeleton การ์ด+ตาราง |
| ผิดพลาด | ดึงราคาบางส่วนไม่ได้ | แสดงพอร์ตด้วยค่าล่าสุด + price-status stale ต่อรายการ (ไม่ทั้งจอ error) — F003 AC-E01 |
| ไม่มีสิทธิ์ | ยังไม่ล็อกอิน / session หมด | หน้าให้ล็อกอิน LINE/Google (ไม่แสดงข้อมูลการเงิน) — NFR-03 |

### 5.2 หน้าเพิ่ม/แก้สินทรัพย์ (Add asset)

| ข้อกำหนดที่รองรับ | F001 |
|---|---|

| สถานะของหน้า | ผู้ใช้เห็นอะไร |
|---|---|
| มีข้อมูล (แก้) | ฟอร์มพร้อมค่าที่มี — ชื่อ/ประเภท/จำนวน/ราคาต้นทุน/**broker channel (บังคับ)** |
| ยังไม่มีข้อมูล (เพิ่มใหม่) | ฟอร์มว่างพร้อม placeholder |
| กำลังโหลด | ปุ่มบันทึก state "กำลังบันทึก…" disable |
| ผิดพลาด | inline error ต่อช่อง (กรอกไม่ครบ/ติดลบ/ไม่เลือก broker) เลื่อน focus — F001 AC-E01/E02/E04 · เตือนซ้ำ AC-E03 |
| ไม่มีสิทธิ์ | เด้งไปล็อกอิน |

### 5.3 หน้า Allocation & rebalance

| ข้อกำหนดที่รองรับ | F002, F006 |
|---|---|

| สถานะของหน้า | ผู้ใช้เห็นอะไร |
|---|---|
| มีข้อมูล | donut ปัจจุบัน + แถบเป้าหมาย + rebalance gap ต่อคลาส |
| ยังไม่มีข้อมูล | ยังไม่ตั้งเป้า → ชวนตั้งเป้า/ทำแบบประเมิน (F007) |
| กำลังโหลด | skeleton |

### 5.4 หน้าแบบประเมินความเสี่ยง (Risk assessment)

| ข้อกำหนดที่รองรับ | F007 (กรอบ ก.ล.ต. — ดู REQ ข้อ 8) |
|---|---|

| สถานะของหน้า | ผู้ใช้เห็นอะไร |
|---|---|
| มีข้อมูล | คำถาม → ผล risk level 1–5 + allocation "ตัวอย่าง ปรับได้" |
| ยังไม่มีข้อมูล | เริ่มทำแบบประเมิน (ไม่บังคับ — ข้ามได้ F007 AC-E03) |
| กำลังโหลด | — |
| ผิดพลาด | ทำไม่ครบ → ไม่คำนวณ แจ้งข้อที่ยังไม่ตอบ (F007 AC-E01) |

| ไม่มีสิทธิ์ | เด้งไปล็อกอิน |

> หน้านำเข้า Excel (F005) ใช้รูปแบบฟอร์ม upload — empty/loading/error(ระบุแถว/คอลัมน์ผิด F005 AC-E01)/unauthorized เช่นเดียวกัน
