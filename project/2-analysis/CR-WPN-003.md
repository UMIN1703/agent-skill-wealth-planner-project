**Proposed change**

| | Text |

**Impact** — effort: 1 lib (parse) + ปุ่มใน SlipReview · metrics: ไม่กระทบ · **ไม่มี Class B / ไม่มีค่าใช้จ่าย** (แลกกับความแม่นต่ำกว่า Claude)

**ของที่ยังไม่พร้อม:** ไม่มี — ใช้งานได้เลย (ดาวน์โหลด worker/lang จาก CDN ครั้งแรก ~10-15MB)

**Proposed change**

| | Text |
|---|---|
| **Current (F009 AC-04)** | อัปไฟล์รูปขึ้น Google Drive ของผู้ใช้ แล้วใส่ลิงก์ไฟล์ในแถว · ตารางไม่มีหัวคอลัมน์ · มี 7 คอลัมน์ (วันที่/ประเภท/ยอด/บันทึก/ลิงก์รูป/รหัส/เวลา) |

**สถาปัตยกรรม (decide-and-log):** `SLIP_SHEET_HEADERS` (ไทย) + `SLIP_SHEET_COLUMNS` (คีย์) เรียงตรงกัน · `driveSync.ensureLedger` append หัวคอลัมน์ครั้งเดียวตอน "สร้างใหม่" เท่านั้น (ชีตเดิมที่มีอยู่แล้วไม่ถูกแตะ) · `parseChannel` ใน slipParse จับชื่อธนาคาร/วอลเล็ตไทยยอดนิยม · assetType/channel เป็น **ช่องไม่บังคับ** (รายการที่ไม่ใช่สินทรัพย์ เช่น ค่าธรรมเนียม เว้นได้)

**Impact** — effort: แก้ slip.ts (types+row+header) · driveSync.ensureLedger · SlipReview (2 ช่อง) · slipParse (parseChannel) · tests +3 · **ไม่มี Class B**

**ของที่ยังไม่พร้อม:** ชีต "WealthPlaner Ledger" เดิมที่สร้างไว้ก่อนหน้า (2 แถวทดสอบ รูปแบบเดิม 7 คอลัมน์ ไม่มีหัว) จะ**ไม่ถูกเติมหัวย้อนหลัง** — เจ้าของต้องลบชีตเดิมทิ้ง เพื่อให้ระบบสร้างชีตใหม่พร้อมหัวคอลัมน์ + 9 คอลัมน์ในการบันทึกครั้งถัดไป
