## 3. Requests

### CR-13 · แยกหน้า `/assets` ออกจากหน้าแรก (หน้าแรก = ภาพรวม)
รายการสินทรัพย์ (เทียบแท็บ **Assets** ในชีต) ย้ายออกจากหน้าแรกไปหน้า `/assets` ของตัวเอง ·
หน้าแรก `/` เหลือเป็น "ภาพรวม" (hero + สถิติ + allocation + ภาษี) เทียบแท็บ **Dashboard** ·
ใช้ `loadAssets()` ตัวเดียวร่วมกัน (`src/lib/portfolioData.ts`) ไม่ให้ logic หลุดจากกัน

### CR-14 · หน้า `/activity` รายการล่าสุด
แสดงสินทรัพย์ที่เพิ่ง เพิ่ม/บันทึก เรียงใหม่→เก่า (จาก `created_at`) **จัดกลุ่มตามวัน**
(วันนี้/เมื่อวาน/วันที่) · แต่ละแถวมี **ป้ายการกระทำ ซื้อ(เขียว)/ขาย(แดง)/สับเปลี่ยน(ฟ้า)** ·
เพิ่มฟิลด์ `action` (`buy|sell|switch`) ไว้รองรับ model Transactions ภายหลัง — ของจริง default = ซื้อ
(ทุกการบันทึก holding = เพิ่ม/ซื้อ), เดโมวนให้เห็นครบ 3 แบบ

### CR-15 · ปรับ bottom nav + ย้าย Rebalance/Import เข้า Profile
Bottom nav ใหม่ = **พอร์ต · สินทรัพย์ · เพิ่ม · ล่าสุด · โปรไฟล์** (เดิม พอร์ต/ปรับสมดุล/เพิ่ม/นำเข้า/โปรไฟล์) ·
ย้าย **ปรับสมดุล (`/rebalance`)** และ **นำเข้าจาก Google Sheet (`/import`)** เป็นแถวในการ์ด Profile settings

### CR-16 · หน้าตั้งค่าใน Profile ใช้งานได้จริง (เดิม mockup "เร็วๆ นี้")
- `/profile/account` — แก้ "ชื่อที่แสดง" (เก็บ localStorage → แสดงที่หัวโปรไฟล์) + ข้อมูลบัญชี (อ่านอย่างเดียว)
- `/profile/notifications` — 3 สวิตช์ (สรุปสลิป/เตือนเบี่ยงเป้า/สรุปรายเดือน) + สถานะช่องทาง LINE
- `/profile/drive` — สถานะเชื่อม Google Drive (จาก session) + สิทธิ์ + ลิงก์ไฟล์ ledger (`findLedger`) / ชวนเชื่อม Google
- `/profile/privacy` — "ซ่อนจำนวนเงิน" (มีผลจริงกับ hero หน้าพอร์ต) + ล้างข้อมูลในเครื่อง + บอกที่เก็บข้อมูล
- การตั้งค่าเก็บ `localStorage` (ตามสถาปัตยกรรม JWT ปัจจุบัน) · การส่ง LINE push จริง = งานฝั่งเซิร์ฟเวอร์ภายหลัง (ไม่ทำปุ่มหลอก)

### CR-17 · ย้าย logout ไปการ์ด Profile จุดเดียว
ปุ่มออกจากระบบย้ายจาก topbar ทุกหน้า → อยู่ในการ์ดโปรไฟล์ (ปุ่มแบบมีข้อความ) แทน chip
"เข้าสู่ระบบด้วย …" ข้างรูปโปรไฟล์ · `LogoutButton` เพิ่ม variant `label`

### CR-18 · เรียงหมวดตามความเสี่ยง + คืนแถบ "ทั้งหมด"
ลำดับความเสี่ยงกลาง `categoryRiskRank` (portfolio.ts): เงินสด < เงินสำรองฉุกเฉิน < เกษียณ <
ทองคำ < หุ้นไทย < หุ้นต่างประเทศ < คริปโต · ใช้เรียงทั้ง chip `/assets` และการ์ด allocation ·
แถบ "ทั้งหมด" กลับมาเป็นค่าเริ่มต้น
