เปิดโครงการใหม่สำหรับนักเรียน โดยใช้ skill `project-intake`

ขั้นตอน

1. ตรวจว่ามี `project/project.yml` อยู่แล้วหรือยัง
   - **มีอยู่แล้ว** — อ่านทั้งไฟล์ แล้วรายงานว่าตอบไปแล้วกี่ช่อง ค้าง `TBD` กี่ช่อง
     อยู่ระยะไหน จากนั้นถามว่าจะเติมช่องที่ค้าง หรือจะเริ่มโครงการใหม่ทับของเดิม
     **ห้ามเขียนทับโดยไม่ถาม**
   - **ยังไม่มี** — ไปข้อ 2

2. เรียก skill `project-intake` แล้วถามคำถามรอบเปิดโครงการ 5 ข้อ **รวมเป็นข้อความเดียว**
   ถ้าผู้ใช้ให้ข้อมูลบางส่วนมาแล้วในคำสั่งนี้ ให้ถามเฉพาะที่เหลือ

3. สรุปคำตอบให้ผู้ใช้ยืนยันก่อนเขียนไฟล์ — ข้อนี้ห้ามข้าม

4. เมื่อยืนยันแล้ว
   - เขียน `project/project.yml` จาก `assets/project.yml.template` ของ skill
     `project-intake` โดยคง comment ในไฟล์ไว้ทั้งหมด
   - สร้าง `project/REGISTER.md` จาก `assets/register-template.md` ของ skill
     `document-control` แล้วแทน `XXX` ด้วยรหัสโครงการ
   - ตั้ง `stage: intake`
   - ทุกช่องที่ผู้ใช้ตอบว่าไม่รู้ ให้เขียน `TBD — ต้องการ [คน/ข้อมูล]`
     และเพิ่มรายการใน `open_questions`
   - ตัวเลขที่ผู้ใช้ประมาณเอง ให้เพิ่มรายการใน `assumptions`

5. **ห้ามสร้างเอกสารอื่น** ไม่ต้องสร้าง PRD ไม่ต้องสร้างโฟลเดอร์ที่เต็มไปด้วยไฟล์เปล่า
   เอกสารสร้างทีละฉบับด้วย `/doc-new` เมื่อถึงคิวของมัน

6. ปิดท้ายด้วยสามบรรทัด — เขียนอะไรไปบ้าง · ยังค้าง `TBD` กี่ช่องและช่องไหน
   · คำสั่งถัดไปที่ควรรัน (ปกติคือ `/gate` เพื่อดูว่าขาดอะไร หรือเรียก skill
   `product-owner` เพื่อเริ่มเขียน PRD)
